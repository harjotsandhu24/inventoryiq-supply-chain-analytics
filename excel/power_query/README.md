# Power Query (M) import scripts

These scripts load the pipeline's CSV exports into Excel tables with explicit column types, so a workbook can be refreshed with **Data > Refresh All** after rerunning the pipeline.

They were written for Excel but **not executed in it**, because the build environment has no Excel installation. The project's workbook (`deliverables/<source>/InventoryIQ_Analysis.xlsx`) is generated by openpyxl and validated with the `formulas` recalculation engine instead. If a script fails in your Excel version, check the folder path first.

## Use

1. In Excel: **Data > Get Data > From Other Sources > Blank Query**, then open the **Advanced Editor**.
2. Paste a `.pq` file and set `CsvFolder` to your absolute path to `deliverables\m5\csv` (or `deliverables\synthetic\csv`).
3. Choose **Close & Load To...** and load it as a table. Repeat for each script.

| Script | Loads | Notes |
|---|---|---|
| `replenishment_recommendations.pq` | `replenishment_recommendations.csv` | One row per product-store, Balanced settings |
| `planning_inputs.pq` | `planning_inputs.csv` | Forecast mu and sigma, supplier terms, simulated stock |
| `simulation_summary.pq` | `simulation_summary.csv` | Policy comparison for both windows |
| `inventory_ledger_demo.pq` | `inventory_ledger_demo.csv` | Daily simulated ledger (about 160k rows); adds a calendar date and a balance check |
